# Deep Shift: Vesper — 美術方向與素材需求（科幻版）

> 給畫師或 AI 生成用的規格。只談畫面，不含劇情劇透。

## 一句話

**藍領工業科幻**：一顆大氣不能呼吸的邊境星球，人類穿著打補丁的壓力服，在企業的礦區裡輪班。畫面要先讓人覺得「舒服、可愛、想一直看」，之後才慢慢看出這裡其實很壓迫。

畫法採**手繪卡通**：輪廓清楚、造型好認，有一層亮面和一層暗面，細節量參考 Idle Isekai Mining。設計語言參考 *The Expanse*、*Alien*（Nostromo）、*Hardspace: Shipbreaker*：東西用舊了、修過、到處印著公司 logo。

## 兩種視覺語言

| | 赫利昂企業 | 工人 |
|---|---|---|
| 顏色 | 冷白、青色 `#9fe0ef`、乾淨的面板 | 暖琥珀色 `#f6b73c`、橘色警示、磨損的金屬 |
| 材質 | 全息投影、玻璃、無縫外殼 | 焊痕、補丁、膠帶、手寫標籤 |
| 出現在哪 | 總部大樓、監視器、無人機、公告、介面 | 宿舍、食堂、工具、坑道 |

兩種語言會在畫面上互相拉扯。後期劇情會出現手寫的「隱藏升級」，跟赫利昂乾淨的介面形成對比。

## 世界外觀

- **天空**：Vesper 的意思是「黃昏星」，畫面永遠是黃昏。琥珀色混紫色的混濁大氣，有一顆帶環的氣態巨行星和一顆很亮的黃昏星。偶爾有沙塵飄過。
- **地表**：鏽紅色岩地，長著一叢叢紫色的外星苔蘚。
- **人**：每個人都穿壓力服、揹氧氣瓶。頭盔要用**透明面罩**，看得到臉。設計原則之一是「人要被看見」，臉不能被擋住。
- **氧氣**：氧氣是公司賣的。O₂ 工廠、儲氣球、管線要畫得很顯眼，上面貼著赫利昂的價目標籤。

### 劇情需要的狀態變化（等故事定案再確認）

### 音效（選配，但效果很大）

電漿鑽、磁浮升降艙運作、氣密閘門開關、貨橇懸浮聲、信用點入帳、升級、按鈕音效。背景音樂要有黃昏工業的氛圍，帶一點憂鬱。

## 技術規格

- 檔案：PNG、sRGB、透明背景
- 角色：面向右，腳底對齊每一格的底部中央
- 一致性：光源方向統一（黃昏光從右上來），外框粗細和顏色統一
- 交付：在對話中上傳，或放進 repo 的 `public/assets/`。檔名和資料夾由開發端整理
